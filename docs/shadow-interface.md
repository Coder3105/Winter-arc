# Shadow interface

The header navigation lives in a toggleable modal System menu. It supports Escape,
backdrop dismissal, keyboard focus containment and focus restoration. Exit appears
only inside the menu and shows pending feedback while the session is revoked. A
failed logout leaves the owner in the app with a retryable error.

Beru, Igris and Iron portraits are decorative fan artwork, not new unlocks or ranks.
Perfect calendar dates rotate portraits; the profile has a shadow guard; streak and
reward panels retain their existing calculated counts and qualification policies.
No tracking, XP, reward, recovery or authentication policy is changed.

Beru loading uses the generated portrait with CSS floating, aura, orbit and particle
animation. It reflects actual pending work, never a fabricated progress percentage.
Reduced-motion preferences disable animation. Next Image serves appropriately sized
portrait derivatives; original assets are in `public/shadows/`.

## Generated assets and prompts

Created with the imagegen skill and built-in image generation. These are original
fan-art illustrations, not official artwork. No external image downloads were used.

## Browser verification

Headless Chrome checked widths 320, 390, 430, 768 and 1280 without horizontal
overflow; menu open/close/Escape and focus containment; delayed failed logout
feedback; reduced-motion behavior; and absence of browser errors. The temporary
fixture route used for these checks is not shipped. No real owner session or source
records were modified during visual verification.
